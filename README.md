# Rahim Siddiqui | Fullstack Engineer

Welcome to my professional portfolio. I engineer digital experiences where technical precision meets creative soul. This project showcases my skills in building high-performance, accessible, and scalable web applications.

## 🚀 Overview

This portfolio serves as a central hub for my professional work, featuring dynamic animations, a seamless user experience, and a clean, modern design. It's built with the latest web technologies to ensure speed, accessibility, and SEO friendliness.

## ✨ Key Features

- **Interactive Typewriter Effect**: A smooth, sequential reveal of text on the landing page.
- **Waving Hand Animation**: A hover-triggered wave animation on the hand emoji using Framer Motion.
- **Responsive Design**: Fully optimized for mobile, tablet, and desktop views.
- **Dark/Light Mode**: Seamless theme switching with persistent user preference.
- **Performance Optimized**: Built using Vite and React Suspense for lightning-fast load times.
- **Clean Navigation**: Intuitive routing to Projects, About, Blogs, and Contact pages.

## 🛠️ Tech Stack

- **Frontend**: [React 19](https://react.dev/), [Vite 7](https://vitejs.dev/), [Tailwind CSS 4](https://tailwindcss.com/)
- **Animations**: [Framer Motion 12](https://www.framer.com/motion/)
- **Icons**: [Lucide React](https://lucide.dev/)
- **Routing**: [React Router 7](https://reactrouter.com/)
- **Database**: [MongoDB](https://www.mongodb.com/) (Backend Integration Ready)

## 📁 Project Structure

```text
/src
  /components     # Reusable UI components
  /pages          # Page components (Home, Projects, etc.)
  App.jsx         # Main application entry and routing
  main.jsx        # Root entry point
  index.css       # Design system and Tailwind configuration
```

## ⚙️ Getting Started

To run this project locally:

1. **Clone the repository**:

   ```bash
   git clone https://github.com/Rahimsiddiqui/Portfolio.git
   ```

2. **Navigate to the project directory**:

   ```bash
   cd Portfolio
   ```

3. **Install dependencies**:

   ```bash
   npm install
   ```

4. **Start the development server**:
   ```bash
   npm run dev
   ```
